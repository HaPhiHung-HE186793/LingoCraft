# Fixture reference

Các ví dụ là **draft để developer test**, chưa được một reviewer con người ký duyệt trong dự án. Schema pass không có nghĩa nội dung được expert-approved.

Public GameSpec được phép dùng trong renderer sau authorization. Private key chỉ dùng server/test fixture; không copy vào web bundle. Offline practice có policy riêng.

Scene Builder của vertical slice được đánh dấu practice_only đối với unaided recall. Các biến thể Nhật được chấp nhận cho ngữ cảnh đã xác định; không dùng làm quy tắc thay thế に/へ trong mọi câu. Từ 学校 đọc がっこう/gakkō; 大学 đọc だいがく/daigaku.

Script validation kiểm tra schema, ID references, token sequence, hint levels, public/private split và chính sách eligibility minh họa. Không kiểm tra database isolation hoặc gọi FSRS thật.
